# AURA — Open Source Voice Assistant 🎙️

AURA é um assistente de voz desktop open source desenvolvido para automatizar tarefas simples do dia a dia no computador através de comandos de voz.

Com ele você pode controlar funções do sistema, abrir URLs, criar rotinas automatizadas e expandir funcionalidades facilmente.

---

# ✨ Funcionalidades

- 🎤 Reconhecimento de voz em tempo real
- 🔊 Controle de volume do sistema
- 🌐 Abertura automática de URLs
- ⚡ Execução de ações rápidas e rotinas
- 🖥️ Integração com comandos do sistema operacional
- 🧩 Estrutura preparada para expansão de comandos personalizados

# 🚀 Como usar

## 1. Inicie o reconhecimento de voz

Para que os comandos por voz funcionem corretamente, garanta que o executável abaixo esteja rodando:

```bash
/resources/speech_assistant_app.exe
```

Esse executável é responsável pelo reconhecimento e processamento dos comandos de voz.

---

# 🎛️ Comandos suportados

## 🔊 Controle de Volume

### Aumentar volume
```bash
volume up
```

### Diminuir volume
```bash
volume down
```

# 📌 Objetivo do Projeto

O objetivo da AURA é fornecer uma base simples, expansível e eficiente para automação desktop por voz, permitindo que desenvolvedores criem novas integrações, rotinas e sistemas inteligentes de interação com o computador.
